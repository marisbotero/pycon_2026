# ✅ Respuestas del taller

Esta carpeta contiene soluciones de referencia. Intenta cada actividad antes de
abrirlas: no existe una única forma correcta de escribir un prompt, pero sí
podemos comprobar si contiene los elementos necesarios.

## Cómo comparar

No copies la solución completa de inmediato:

1. ejecuta tu versión;
2. compara su decisión JSON;
3. comprueba el resultado;
4. identifica una diferencia;
5. decide si tu solución también cumple el contrato.
